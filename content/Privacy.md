# Privacy Policy
PolyTigr does not sell personal data.

This site is a static portfolio and storefront. It does not run accounts, analytics trackers, or comment systems on polytigr.com itself. Marketplace purchases (Gumroad, Fab, CGTrader, and similar) use those platforms' own privacy policies.

If you email [contact@polytigr.com](mailto:contact@polytigr.com), I keep the message only as long as needed to reply.
